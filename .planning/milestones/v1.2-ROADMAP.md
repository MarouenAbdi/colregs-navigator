Reached a lint-clean baseline (0 errors) via a reviewed two-pass `eslint --fix` + `--fix --suppress-all`, plus two zero-dependency differentiators: a `no-restricted-imports` rule that lint-enforces the `src/domain/` architecture boundary (not just documents it), and a custom rule catching stale Phase/Plan/REQ-ID comment references. Code review caught and fixed a real regression during closeout: the lint-clean autofix pass silently changed the Sandbox chart border/save-banner corner radius ahead of Phase 11's planned, human-verified version of that exact change — restored to the exact original pixel value and pinned against a repeat via a scoped rule-config ignore pattern.

## Milestone Summary

**Key Decisions:**

- v1.2 is a tech-debt/hygiene milestone only — no new user-facing features, `classifyEncounter()` and all COLREGS rule outputs stayed byte-identical throughout.
- Phase order locked: ESLint setup (10) before everything else; Tailwind fixes (11) before the refactor (12) since both touch the same two files; comment cleanup (13) last as lowest-risk/no ordering dependency.
- `typescript-eslint` locked at `recommended` (non-type-checked) tier; `strict`/`strict-type-checked` explicitly out of scope.
- Lint-clean baseline reached via `eslint --fix`/`--fix --suppress-all`, never via mass rule-disabling.
- `VesselGroup.tsx` extracted last, as one atomic verbatim cut-paste — this exact code caused two prior hit-testing regressions (Phase 4, Phase 8).
- Tailwind class-name fixes and comment cleanup both done by hand, file-by-file/comment-by-comment — this codebase has known false-positive traps for any mechanical/regex pass.

**Issues Resolved:**

- `typescript-eslint`/`eslint-config-next` incompatibility with locked TypeScript 7.0.2 (tsgo) — resolved via `@next/eslint-plugin-next` + `@babel/eslint-parser` bypass.
- A silent corner-radius regression introduced by the Phase 10 autofix pass, caught by code review and fixed before it could compound with Phase 11's planned change.
- A session interruption mid-Phase-13-Wave-1 (6 killed worktree-executor agents), recovered via manual orchestrator close-out with zero lost work.
- A self-inflicted regex collision, a stray test-name tag, and a bare comment reference — all found and fixed during Phase 13's own final verification sweep (13-08).

**Issues Deferred:**

- None new this milestone.

**Technical Debt Incurred:**

- None — this milestone's explicit purpose was reducing technical debt (lint tooling, deprecated classes, oversized files, stale comments), not incurring it.
