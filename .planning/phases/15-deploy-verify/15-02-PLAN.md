       DIRECT (non-pooled) connection string variant -- confirm the hostname does NOT

    4. Go to vercel.com and sign up (or sign in). Click "Add New" -> "Project", and import
       the GitHub repository `MarouenAbdi/colregs-navigator`.
    5. Leave the Build & Development Settings at Vercel's Next.js zero-config defaults -- do
       not manually override the build command; Vercel auto-detects and prefers the
       `vercel-build` package.json script over the plain `build` script.
    6. Before or immediately after the first deploy, go to Project Settings -> Environment
       Variables and add exactly one variable: name `DATABASE_URL`, value = the direct
       connection string from step 3, scope = Production. This is the full scope of
       DEPLOY-03 (`.env.example` currently defines exactly this one variable, nothing else
       is needed).
