## Interaction Contract (phase-specific — supplements the standard template sections above)

This phase is interaction-heavy relative to visual surface, so the exact hover/focus/touch states from CONTEXT.md decisions are captured here as the binding contract for the executor:

| State | Behavior | Source |
|-------|----------|--------|
| Default (no hover/focus) | Overlay button + chart scrim: opacity 0 on fine-pointer devices (`@media (hover: hover)`); low, non-zero opacity on coarse-pointer/touch devices (`@media (hover: none)`) so the affordance is discoverable without a "reveal" tap | D-01, D-05 |
| `:hover` OR `:focus-within` on the card wrapper | Button + scrim fade to full opacity; whole-card border/shadow polish (`group-hover:border-primary/40 group-hover:shadow-sm` today) must also apply on `group-focus-within`, not hover-only | D-04, D-06, GAL-06 |
| Touch `:active` / focus | Full-opacity button + scrim (same end-state as hover) | D-05 |
| Click | `requestLoad(vesselA, vesselB)` fires immediately; `document.getElementById("sandbox")?.scrollIntoView()` fires in the same handler, in parallel, with no explicit `behavior` override (relies on the existing global CSS `scroll-behavior: smooth` gated behind `prefers-reduced-motion: no-preference`) — do NOT hardcode `behavior: "smooth"` in the JS call | D-07, D-08 |
| Second click (different card) | State genuinely replaces the first (Context `requestId`-keyed effect, not object-identity-keyed) — must be human-verified, not just type-checked | Roadmap success criterion 4 |
| Post-load | No flash/highlight animation — the changed chart/verdict after scroll is the sole acknowledgment | D-09 |

Button component base: shadcn `Button` `variant="default"` (solid `bg-primary text-primary-foreground`, matches D-03's "not outline/ghost" requirement — outline is what Sandbox's own Reset button already uses, so `default` is the correct differentiator).

Card wrapper: replace the current `<Link href={...} className="group ...">` with a plain `<div className="group ...">` (no `href`, no `Link` import) — `TryOnSandboxButton` becomes the sole interactive/focusable element inside the card, per D-04 and the Out of Scope ruling against a dual `Link`+button card.
